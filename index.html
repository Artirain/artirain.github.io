    artirain-rag
    
          
    RAG · Qdrant · LangGraph
    
        
    
        
    
          Ответы по корпусу документов с цитированием источников. Гибридный поиск
          (dense + BM25, слияние RRF на стороне Qdrant), cross-encoder реранкер и
          граф на LangGraph: retrieve -> оценка контекста -> генерация -> проверка ->
          переписать запрос и повторить. Ответ без опоры на контекст не выдаётся.
        
    
        
    
          
    recall@6 на внешнем корпусе (154 стр. доков)
    
          
    
            
    dense28%
    
            
    + реранк60%
    
            
    + граф68%
    
          
    
          
    
            Полезных ответов по LLM-судье: 65% -> 95% -> 100%. Узкое место было
            в поиске, а не в промпте - это и показали evals.

    job-hunter
    
          
    агент · Playwright · SQLite
    
        
    
        
    
          Агент ищет вакансии, LLM отбирает подходящие - в том числе семантически,
          по смыслу «компания реально использует ИИ», - пишет сопроводительное под
          конкретную вакансию и откликается. Дальше читает чаты с рекрутёрами:
          простое отвечает сам, деньги и переезд отдаёт мне черновиком в Telegram.
        
    
        
    
          Этот сайт вы, скорее всего, открыли из письма, которое написал он.
        
    
        
    
          
    этапы прогона
    
          
    fetch -> filter -> classify -> letter -> apply -> chat
    
          
    
            Состояние в SQLite: дедуп по вакансии, ретраи при сетевых сбоях,
            лимит откликов на прогон. Запуск по расписанию, отчёт - карточкой в Telegram.

    finetune-vs-prompt
    
          
    PyTorch · LoRA · evals
    
        
    
        
    
          Когда дообучить маленькую модель выгоднее, чем промптить большую.
          LoRA-адаптер (r=16, 2.2M параметров, 8.6 МБ) поверх Qwen2.5-0.5B на
          финансовом сентименте, честный сплит и общий eval-харнесс для всех
          подходов.
        
    
        
    
          
    accuracy / латентность одного ответа
    
          
    
            
    Qwen2.5-0.5B + LoRA89.7%86 мс
    
            
    qwen2.5:7b zero-shot73.5%2.6 с
    
            
    gpt-5.5 zero-shot72.9%7.7 с
    
          
    
          
    Тренировка - 15 минут на одной RTX 3060.
