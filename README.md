## Локально

```
python -m http.server 8899
```

## Что внутри

- Герой с дуотон-портретом (оригинальный цвет проявляется на ховере).
- Живой конвейер: сырой текст проходит стадии и превращается в JSON —
  три реальных проекта по одной схеме. Уважает `prefers-reduced-motion`.
- Опыт, проекты с измеренными результатами, стек, контакты.

Данные для правок лежат прямо в разметке; примеры конвейера — в `SAMPLES` в `main.js`.
